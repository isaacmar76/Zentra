# 01-REQUERIMIENTOS.md
## PROYECTO: ZENTRA V1.2

### 1. OBJETIVO
App móvil para micronegocios en Colombia. Sin facturación electrónica.
Reemplazar cuadernos y Excel. Enfoque: Simple y rápido.

### 2. PÚBLICO OBJETIVO
2 perfiles:
A. RETAIL: Tiendas, minimercados, papelerías
B. SERVICIOS: Papelería creativa, salones, catering. Caso: TATIANA

### 3. MÓDULOS PRINCIPALES
1.  Login y Selección de Modo
2.  Dashboard Adaptativo
3.  Catálogo: Productos o Servicios
4.  Clientes
5.  FLUJO RETAIL: Venta Rápida + Caja + Inventario
6.  FLUJO SERVICIOS: Proyectos + Gastos + Pagos + Estados
7.  Tareas y Alertas
8.  Reportes Básicos
9.  Configuración

### 4. REGLAS CLAVE
1.  Todo funciona sin internet. Sincroniza después.
2.  Sin IVA, sin DIAN. Cálculos simples.
3.  Tonos Nude, Blush, Beige. Femenino y limpio.
4.  Botón extra: VER PEDIDOS PRONTO A VENCER para modo Servicios.

### 5. TECNOLOGÍA
Flutter + Supabase + Almacenamiento local
