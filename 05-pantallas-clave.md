# 05-PANTALLAS-CLAVE.md
## TEXTO Y COMPONENTES DE CADA PANTALLA

### 1. LOGIN
Título: Bienvenido a ZENTRA
Campos: Email, Contraseña
Botones: INICIAR SESIÓN, REGISTRARSE

### 2. SELECCIONAR MODO
Título: ¿Cómo trabaja tu negocio?
Opción A: RETAIL - Tienda, Minimercado
Opción B: SERVICIOS - Papelería, Salón, Catering
Botón: CONTINUAR

### 3. DASHBOARD RETAIL
Tarjetas: Ventas Hoy, Ganancia Hoy, Productos Bajos
Botones: NUEVA VENTA, VER INVENTARIO, CUADRE DE CAJA

### 4. DASHBOARD SERVICIOS - EL DE TATIANA
Tarjetas: Ingresos Mes, Gastos Mes, Proyectos Activos
Botones: + NUEVO PROYECTO, VER PEDIDOS PRONTO A VENCER, VER CLIENTES

### 5. NUEVO PROYECTO
Título: NUEVO PROYECTO
Campos: Nombre del Proyecto, Cliente, Fecha de Entrega
Sección: Servicios
    - [ ] Invitaciones
    - [ ] Centros de mesa  
    - [ ] Banderines
Botón: GUARDAR PROYECTO

### 6. DETALLE DE PROYECTO
Título: DETALLE DE PROYECTO
Secciones: Servicios del Catálogo, Gastos del Proyecto, Pagos, Estado
Estados: En Diseño, En Producción, Listo, Entregado
Botones: + AGREGAR GASTO, + REGISTRAR PAGO

### 7. VER PEDIDOS PRONTO A VENCER
Título: VER PEDIDOS PRONTO A VENCER
Subtítulo: X pedidos vencen en los próximos 3 días
Lista: Nombre Proyecto, Fecha Vence, Faltan X días
